# My cursor population

Your work is saved in this browser, on this device, until you export and commit it. Switching devices or clearing the browser loses unexported work. Export and commit often.

A draft ZIP keeps unfinished work. A hand-in ZIP checks each cursor for three facts, three rules, one Cannot, one meeting voice and one Otherwise action. Downloading either ZIP does not submit it or send it to GitHub.

## My repository

Each student owns their own repository. Do not work inside the course source repository.

1. Open MDST-4650-Game-Studio on GitHub. Choose Use this template → Create a new repository, and make your own public repository.
2. Clone your repository with GitHub Desktop. In the Kit, open Your files and export a draft or hand-in ZIP. Unzip its contents into your cloned folder, replacing files of the same name.
3. In GitHub Desktop, review the changes. Write a commit message saying what changed and why, commit, then Push origin. Repeat as you work.

[Student template](https://github.com/NevenLochhead-bit/MDST-4650-Game-Studio) · [Cursor Kit](https://interactive-media-game-studio.netlify.app/kits.html) · [Course Ship date and submission instructions](https://interactive-media-game-studio.netlify.app/overview.html#schedule)

If the template route is unavailable, download the starter ZIP in Your files, unzip it, then use GitHub Desktop to create a repository in that folder and publish it with Keep this code private unchecked.
